# GlassNote web sitesi

GlassNote masaüstü uygulamasının tanıtım web sitesi. Henüz geliştirme aşamasında.

| Klasör | İçerik |
|---|---|
| [`frontend/`](frontend/) | Kullanıcının gördüğü site (sayfalar, tasarım, istemci kodu) |
| [`backend/`](backend/) | Sunucu tarafı (API, veri, sunucu işlemleri) |

Masaüstü uygulamasının kodu bu klasörden bağımsızdır: [`../uygulama/`](../uygulama/).
